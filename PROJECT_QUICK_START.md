# 🚀 Profitability Metrics GitHub Project - Quick Start

**Seu projeto de 12 issues em 3 sprints já está pronto para ser criado no GitHub!**

## ⏱️ 5 Minutos para Começar

### Step 1: Token
```powershell
# 1. Gere em https://github.com/settings/tokens/new
# 2. Copie o token
# 3. Execute:
$env:GITHUB_TOKEN = 'seu_token_aqui'
```

### Step 2: Executar
```powershell
cd C:\storage\workspace\kotlin\emerion-load-service
python .github\create_github_issues.py
```

### Step 3: Criar Project
- Acesse: https://github.com/arnaldotecadm/projects/new
- Nome: "Profitability Metrics & BI Dashboard"
- Template: Table
- Clique: Create

### Step 4: Adicionar Issues
- No project: "Add items" → "Add issues from repository"
- Filtro: `label:sprint-1` (depois sprint-2, sprint-3)
- Selecione e adicione
